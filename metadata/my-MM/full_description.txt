Z2M Dash သည် Zigbee2MQTT အတွက် အခမဲ့၊ open-source Android ဒက်ရှ်ဘုတ် ဖြစ်သည်။ ၎င်းသည် သင့်ကိုယ်ပိုင် MQTT broker နှင့် တိုက်ရိုက် ဆက်သွယ်သောကြောင့် cloud အကောင့် မလိုအပ်ဘဲ မည်သည့်ဝန်ဆောင်မှုပေးသူနှင့်မျှ ချည်နှောင်ထားခြင်း မရှိပါ။ သင့်တပ်ဆင်မှုတစ်ခုလုံးကို ဖိုင်တစ်ခုတည်းတွင် သိမ်းဆည်းနိုင်သလို broker မှတစ်ဆင့် ဖုန်းများကြား မျှဝေနိုင်သည်။

ဒက်ရှ်ဘုတ်
• အစုအဝေးများ၏ အုပ်စုများ၊ အစုအဝေးတစ်ခုစီတွင် စက်ပစ္စည်းတစ်ခု၏ အကွက်များ ပါဝင်သည်- အာရုံခံကိရိယာ ဖတ်ရှုချက်များ၊ အဖွင့်/အပိတ် ခလုတ်များနှင့် တစ်ချက်နှိပ် ခလုတ်များ (လိုက်ကာ၏ STOP ကဲ့သို့)။
• သင့်ကိုယ်ပိုင် ယူနစ်နှင့် ဒဿမနေရာများပါသော အာရုံခံ အကွက်များ၊ ဖတ်ရှုချက် အလွန်နိမ့် သို့မဟုတ် အလွန်မြင့်သည့်အခါ အကွက်ကို အရောင်ခြယ်ပေးသည့် ရွေးချယ်နိုင်သော စံပြအပိုင်းအခြား။
• ခလုတ်များသည် နောက်ဆုံးပို့ခဲ့သော အမိန့်သာမက စက်ပစ္စည်း၏ အမှန်တကယ် အခြေအနေကို ပြသည်။
• ရှိနေမှုနှင့် နေရာယူမှု အာရုံခံကိရိယာများကို "တွေ့ရှိသည်" သို့မဟုတ် "လူမရှိ" ဟု ပြသည်။
• အုပ်စု၊ အစုအဝေးနှင့် အကွက်များကို ဆွဲယူချ၍ ပြန်စီနိုင်ပြီး ပြန်ဖျက်နိုင်သည်။ "အပြင်အဆင်ကို လော့ခ်ချရန်" (မူလအားဖြင့် ဖွင့်ထား) သည် မတော်တဆ ရွှေ့မိခြင်းကို တားဆီးသည်။
• စက်ပစ္စည်းတစ်ခုသည် တစ်နာရီကျော် အစီရင်ခံခြင်း မရှိသည့်အခါ (အနီ)၊ ဘက်ထရီ နည်းသည့်အခါ (အပြာ) သို့မဟုတ် Zigbee အချက်ပြ အားနည်းသည့်အခါ (အဝါ) အစုအဝေးကို ဘောင်ခတ်ပြသည်။ အားပြန်သွင်းနိုင်သော NiMH ဘက်ထရီသုံး အစုအဝေးများကို 5% တွင်သာ နည်းသည်ဟု သတ်မှတ်သည်။
• စစ်ထုတ်မီနူးသည် ဘက်ထရီနည်း သို့မဟုတ် အချက်ပြ အားနည်းသော စက်ပစ္စည်းများ၊ သို့မဟုတ် စံပြအပိုင်းအခြားအောက် သို့မဟုတ် အထက်ရှိ စိုထိုင်းဆ အာရုံခံကိရိယာများကိုသာ ပြသည်။
• ဖုန်းများနှင့် Android TV တွင် အလုပ်လုပ်သည်။

တပ်ဆင်ခြင်းနှင့် စင့်ခ်လုပ်ခြင်း
• စက်ပစ္စည်းများသည် သိမ်းဆည်းထားသော (retained) "/app" ဆက်တင် မက်ဆေ့ချ်တွင် ၎င်းတို့၏ အကွက်များကို ဖော်ပြနိုင်သဖြင့် broker တစ်ခုတည်းရှိ ဖုန်းအားလုံးသည် အပြင်အဆင် တူညီစွာ ပြပြီး ဖုန်းတစ်လုံးတွင် ပြောင်းလဲမှုများ အခြားဖုန်းများသို့ ရောက်သည်။
• "အာရုံခံကိရိယာများ ရှာဖွေရန်" သည် broker ကို ဖတ်ရှုချက်များအတွက် စကင်ဖတ်ပြီး "/app" ဆက်တင် မရှိသော စက်ပစ္စည်းများအတွက် အကွက်များ ဖန်တီးသည်။
• "ချိတ်ဆက်ခွင့်ပြုရန်" ဘားသည် Zigbee စက်ပစ္စည်းအသစ်များကို မည်သည့် router မှမဆို ချိတ်ဆက်ခွင့်ပေးပြီး နောက်ပြန်ရေတွက်ချက် ပါသည်။
• TCP, SSL, WS သို့မဟုတ် WSS ဖြင့် broker အများအပြား၊ ကိုယ်တိုင်လက်မှတ်ထိုး လက်မှတ်များ အပါအဝင်။
• ရွေးချယ်နိုင်သော နောက်ခံ ချိတ်ဆက်မှုသည် အက်ပ်ပိတ်ထားချိန်တွင်ပင် ဖတ်ရှုချက်များနှင့် သတိပေးချက်များကို နောက်ဆုံးအခြေအနေ ထိန်းထားသည်။

သတိပေးချက်များ
• မီးခိုး အစီရင်ခံသော မည်သည့်စက်ပစ္စည်းမှမဆို မီးခိုး သတိပေးချက်များ၊ ရွေးချယ်နိုင်သော ကျယ်လောင်သည့် အချက်ပေးသံဖြင့်။
• စိုထိုင်းဆ အာရုံခံကိရိယာသည် ၎င်း၏ စံပြအပိုင်းအခြား အလယ်ကို ကျော်တက်သည့်အခါ ခေါင်းလောင်းသံနှင့် တုန်ခါမှုဖြင့် ရေလောင်းရန် သတိပေးချက်များ။
• ဘက်ထရီ ရာခိုင်နှုန်းကို ပြသော ဘက်ထရီနည်း သတိပေးချက်များ။

အရန်သိမ်းခြင်းနှင့် အမှားရှာခြင်း
• ဆက်တင်တစ်ခုလုံး သို့မဟုတ် broker များကိုသာ ချုံ့ထားသော ဖိုင်အဖြစ် ထုတ်ယူပါ။ အရန်များကို မူလအားဖြင့် ကုဒ်ဝှက်ထားသည် (AES-256-GCM)။
• အားလုံးကို ပြန်ယူပါ သို့မဟုတ် broker များကိုသာ ပေါင်းထည့်ပါ။
• သို့မဟုတ် သိမ်းဆည်းထားသော MQTT မက်ဆေ့ချ်မှတစ်ဆင့် အရန်ကို ထုတ်ပြန်ပြီး ပြန်ယူပါ၊ ဖိုင်ရွှေ့ရန် မလိုပါ။
• တိုက်ရိုက်၊ စစ်ထုတ်နိုင်သော "Terminal" သည် MQTT မက်ဆေ့ချ်တိုင်းကို ပြပြီး ပါဝင်အကြောင်းအရာနှင့် ခေါင်းစဉ်များကို စစ်ဆေးနိုင်သည်။

ရွေးချယ်နိုင်သော အွန်လိုင်း ဝန်ဆောင်မှု
"ဘရိုကာ ထည့်ရန်" မျက်နှာပြင်ရှိ "ကုဒ်ဖြင့် တင်သွင်းရန်" ခလုတ်သည် developer လည်ပတ်သော အထောက်အထား ထပ်ဆင့်ပို့ဝန်ဆောင်မှု sync.odiousapps.com ကို အသုံးပြုသည်။ သင်သည် ထိုဆိုက်သို့ ဝင်ရောက်ပြီး သိမ်းထားသော အထောက်အထားကို ရွေးချယ်ကာ broker ၏ hostname၊ အသုံးပြုသူအမည်နှင့် စကားဝှက်ကို ထိုဆာဗာမှတစ်ဆင့် အက်ပ်သို့ ပြန်ပို့သည်။ သင် ခလုတ်ကို တို့၍ ဆက်လုပ်ရန် သဘောမတူမချင်း မည်သည့်အရာမျှ မပို့ပါ၊ broker များကို အမြဲတမ်း လက်ဖြင့် ထည့်သွင်းနိုင်သလို ဖိုင်မှ တင်သွင်းနိုင်သည်။ ထပ်ဆင့်ပို့ဝန်ဆောင်မှု၏ source code သည် အခမဲ့ software ဖြစ်သည် (Unlicense): https://github.com/evilbunny2008/MX3Launcher/tree/main/website
